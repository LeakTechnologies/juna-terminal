# Palette provenance

Only published color data is bundled. No terminal parser, grid, scrollback, renderer, or other
terminal-engine implementation was imported.

Catppuccin Mocha is taken from the official Catppuccin Windows Terminal palette. Its notice is
in `catppuccin-windows-terminal.txt`. The remaining terminal palette records are transcribed into
Juna's schema from the public iTerm2-Color-Schemes Windows Terminal data at revision
`d3e95e4f7140c980988781f21534cf51e327af2c`; the collection notice is retained in
`terminal-palette-collection.txt`. Each record in `assets/themes.json` keeps its exact source URL.
Individual theme authors retain their original rights and attribution; the collection notice
does not replace individual project notices. See THEME_DESIGN.md for the original project links.

The Monokai choice is **Monokai Classic**, not Monokai Pro. Material Dark uses the published terminal
palette record, not code or assets from the newer commercial VS Code successor. No paid theme
software or editor extension is included.

Names identify theme families, not endorsements or an independently verified top-20 usage ranking.
