# Juna 0.1.1-dev16

Drag a file or folder onto the terminal body to insert its local path at the current input
caret. Juna does not add Enter, execute/open it or modify the clipboard. PowerShell paths use
literal quoting; safe cmd paths use quotes, with expansion-sensitive forms rejected. Unknown
shells/alternate-screen apps receive literal paths; nested/remote contexts cannot be inferred.

The title now reads `Juna - v0.1.1-dev16`. Updater checks still recognize older Juna windows.
Release GUI startup no longer attaches to the launcher's console: an isolated interrupt was
shown to terminate dev15 with 0xC000013A. CLI commands retain console output. Child Ctrl+C/Ctrl+Z
semantics are preserved; Ctrl+Z is not universally process suspension on Windows.

The exact reported OpenCode background-server interaction remains subject to user confirmation.
Physical Explorer drag/drop and other-machine acceptance are separate from automated checks.
Tab detachment into a new window is recorded on the roadmap and is not implemented here.

Validation: check, strict all-target Clippy and all 243 standard tests passed. Eight existing
real-window checks and the added optimized-GUI console-isolation regression passed. Native
x64/version/seven-icon verification and bundled-tool pin verification passed. The installed
OpenCode 2.0.31 startup-cancellation probe recovered its interactive shell; the local service
port was occupied, so full TUI/model-interruption acceptance remains unverified. No benchmark
or general OpenCode crash-resolution claim is made. Release assets are verified after tagging.
