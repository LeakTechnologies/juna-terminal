# Juna 0.1.1-dev13

Junafetch identity and local network fields now display `░░░░░`. Hold Shift, then move over
a shaded field to reveal it temporarily. Releasing Shift, leaving the field, switching tabs
or losing focus hides it. Settings → Privacy offers ordinary hover, deliberate-only reveal
and an explicit censorship opt-out that applies to subsequent reports.

Protected values travel through bounded current-user local IPC and remain outside the VT
stream, scrollback and copied text. Unavailable transport leaves fields masked. Plain and
JSON reports remain masked unless censorship is explicitly disabled.

This release protects structured Junafetch fields. Arbitrary command output, including an
independently installed Fastfetch, is not automatically censored yet. Screen recording can
capture deliberately revealed values. Laptop memory and bulk-output performance work remains
open; this change does not claim to resolve those performance limitations.
