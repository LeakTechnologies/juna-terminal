# Juna 0.1.1-dev3

Bundled Junafetch is available as `junafetch` and `fetch` inside Juna sessions, without
installing Fastfetch or changing global PATH. Eight local statistics use compact artwork;
`--plain`, `--json`, `--details` and `--logo compact|full|none` adjust the presentation.

The separate console frontend embeds the pinned lean Fastfetch 2.69.0 detector. Both cache
layers verify SHA-256 before execution. Original licensing notices and source fingerprints
are included in the package. Personal/network identifiers are omitted from reports.

This is a development preview. Terminal-wide masking, protected-value hover reveal, local
Git status and the in-app updater remain unshipped. Checksums are not publisher signatures.
See TERMINAL_TESTING.md for validation evidence and remaining interactive acceptance.
