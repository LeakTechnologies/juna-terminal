# Juna 0.1.1-dev19

Reduce ordinary terminal-output overhead by avoiding unnecessary allocation and grapheme
joining for adjacent printable ASCII characters. Unicode processing and ordered transport
remain unchanged, with exhaustive pair and Unicode/chunking regression coverage.

In three isolated desktop runs, median parent CPU for 4 MiB output fell from 3.52 to 2.50
seconds (about 29%). The separate instrumented engine probe recorded about 98% fewer
allocations. These limited synthetic measurements do not establish laptop/battery or general
terminal performance. Idle private memory remains high and effectively unchanged.

Includes all earlier file-drop, versioned-title, console-isolation and diagnostic repairs.
Physical Explorer drops and the exact OpenCode interruption case still require human testing.
See PERFORMANCE.md and docs/performance/dev19 for raw counters and measurement limitations.

Local validation: check, strict Clippy, all 244 standard tests, nine real-window checks and
isolated OpenCode startup cancellation passed, along with native resources and bundled pins.
The scrollback CPU snapshot baseline is recorded separately; it does not measure actual
mouse-to-presentation latency. Hosted CI and downloadable assets are verified after tagging.
