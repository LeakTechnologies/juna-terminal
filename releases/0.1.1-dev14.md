# Juna 0.1.1-dev14

Use `juna --check-update` to check GitHub Releases without opening a window or downloading.
Use `juna --update` to download and verify a newer release, then confirm installation and restart.
Both use the saved update channel; `--channel stable` or `--channel preview` overrides it for
that invocation. `juna --help` lists the supported commands.

Inside Juna, update requests go to the authenticated hosting window and open its existing
Cancel-first installation confirmation after verification. Sessions stay open until confirmed.
Outside Juna, close other Juna windows and answer the default-No text prompt. Redirected input
does not approve installation. The command reports installer handoff; actual replacement/restart
and failures use the existing helper acknowledgement and recovery reporting.

The executable directory is added only to Juna's child-session PATH. For portable use outside
Juna, run `./juna.exe`; PowerShell can wait for GUI-executable text output using
`./juna.exe --check-update | Out-Host`. No system PATH/profile changes or automatic checks.

Downloads retain HTTPS, checksum/native identity verification, bounded staging and the existing
notices/rollback transaction. Laptop memory and bulk-output improvements remain separate work.
