# Juna 0.1.1-dev21

Tabs can now be rearranged by clicking, holding and dragging. The active session and its
engine stay with the tab, so reordering never restarts or swaps terminal state.

Tab names become `Directory (Shell)`, for example `VideoTools (PowerShell)`. With directory
tracking enabled (now the default), the name follows `cd` through the existing OSC 7 metadata.
Manual renames stay pinned. Command Prompt and Bash show the launch directory until an
equivalent per-shell directory integration exists.

Settings > Terminal now offers a shell choice for new tabs: Windows PowerShell, PowerShell 7,
Command Prompt or Bash. Only these tokens are accepted; imported settings cannot name an
arbitrary executable. A shell chosen with `--shell` or `JUNA_SHELL` still takes precedence,
and existing tabs are never restarted.

Drag geometry and the reorder invariant are unit-tested. The physical drag gesture still needs
manual visual acceptance; this build does not claim it as visually verified. No dependency,
VT semantic, byte-transport or engine-ownership change was made. Hosted release checks and
downloadable assets must be verified after tagging.
