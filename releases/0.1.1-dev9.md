# Juna 0.1.1-dev9

Junafetch now groups expanded local statistics into System, Hardware, Storage, Desktop,
Session and Network sections. Standard covers the Fastfetch categories demonstrated during
testing; Detailed adds board/BIOS/battery/driver fields and Brief retains eight rows.
Unknown values are labelled unavailable, including shell versions the detector cannot identify.

Settings now opens short Appearance, Terminal, Tools and Import/Export categories. Under
Tools → Junafetch, save report detail and compact/full/no artwork. Existing tabs pick up
these preferences on their next fetch command; command-line flags take precedence.

Sensitive identity/network fields remain Hidden placeholders. Actual IP hover reveal and
terminal-wide privacy masking are not implemented by this release. Ctrl+Shift+N follows in dev10.
