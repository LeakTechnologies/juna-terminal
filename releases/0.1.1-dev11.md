# Juna 0.1.1-dev11

Opening Juna normally starts the interactive shell in the user home directory (~), including
launches from an extracted portable folder. Use --cwd DIRECTORY to choose a different folder.
Ctrl+Shift+N explicitly preserves its reported folder or shell launch-folder fallback.

Custom shell-argument launches retain their inherited folder unless --cwd is supplied, so
one-off scripts keep their previous directory behaviour. Missing home/selected directories
produce actionable startup errors. No global working-directory or terminal-engine change.

The approved GitHub updater with install/restart is the next separate development cycle.
