# Juna 0.1.1-dev1 — terminal preferences and menus

Development preview for Windows x64. This is not stable acceptance.

- Tab-strip context menu: New tab, Rename tab and Close tab; terminal menus contain clipboard,
  themes and settings. Repeated context-menu clicks reposition; editing panels ignore right-click.
- Middle-click a tab to open Close tab? with theme-coloured check/cross labels and Cancel selected.
- Optional line numbers in Settings, with a clearer gap and automatic alternate-screen hiding.
- Theme favourite stars, a Favourites section, bulk family controls and immediate wheel scrolling.
- Confirmed theme/font/size/contrast/line-number choices persist automatically. Hover and unfinished
  numeric edits remain temporary. Settings JSON export/import uses validation and an import review.
- Fix the Linux unsupported-backend test compilation failure and embed version/source metadata.

Validation: standard check/clippy/test gates run before landing; local GPU/real-window evidence
is recorded in TERMINAL_TESTING.md. Hosted Windows GNU checks, PE/icon/source metadata, package
contents and SHA-256 checks are required by the release workflow. Physical file-dialog/input,
mixed-DPI and additional GPU/other-machine testing remain human acceptance work.

Not included yet: bundled Junafetch/fetch (next cycle), Git status bar, privacy masking/reveal,
in-app updater, tiled terminals, translations or Android. OpenCode colour queries were deferred.

Settings remain under %LOCALAPPDATA%\Juna; export includes portable appearance preferences and
referenced custom themes, not credentials, history, process environment or tool-cache paths.
