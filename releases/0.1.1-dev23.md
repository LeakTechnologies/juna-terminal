# Juna 0.1.1-dev23

Fix the taskbar button showing a generic icon instead of the Juna dog logo. The window already
exposed the correct small and large icons, but Windows 11 draws a live taskbar button from the
window class icon. Juna now registers the same embedded icon handles with the window class
before showing the window and verifies the result.

Restart Juna after installing: an already-running older instance keeps the class icon it
registered at startup. The executable, AppUserModelID, pinning and relaunch identity are
unchanged. Hosted checks and downloadable assets must be verified after tagging.
