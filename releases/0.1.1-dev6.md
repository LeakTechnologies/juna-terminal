# Juna 0.1.1-dev6

Adds a compact local Git status footer: branch, distinct changed entries, conflicts and
ahead/behind counts against local tracking refs. Counts reflect the last fetch; Juna never
fetches automatically. Settings controls visibility and refresh. Alternate-screen apps regain
the footer space. Failed, oversized or active-filter checks display Unavailable.

OSC 7 tracks local folders. Enable PowerShell folder reporting in Settings and open a new tab
to use the session-local prompt wrapper; existing profiles are not edited. Custom shell arguments
are left intact. Without reporting, the initial folder is labelled as a fallback and retired
on input so a stale repository is not shown as current. Metadata is not exported or logged.

This is a development preview. Expanded grouped Junafetch/profiles and settings submenus are
approved next work, not implemented here. Terminal-wide privacy, pane controls and updater
remain unshipped. Junafetch still omits network identifiers, so IP reveal cannot be tested yet.
