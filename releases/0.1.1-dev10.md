# Juna 0.1.1-dev10

Ctrl+Shift+N opens an independent Juna window with the configured interactive shell and
reported local folder when known, otherwise the launch folder. It does not repeat one-off
shell arguments. Editing panels and IME composition keep ownership of their keyboard input.
Closing either window leaves the other window and its shell running.

Each window writes an exclusive diagnostic file under %LOCALAPPDATA%/Juna/logs. Match the
process ID in the filename to Task Manager, or sort by modification time to find recent logs.

Includes dev9's expanded Junafetch and grouped saved settings. Interactive IP privacy reveal,
terminal panes and the updater remain separate approved/planned work. Human desktop and
other-machine acceptance remain distinct from build and controlled-runtime checks.
