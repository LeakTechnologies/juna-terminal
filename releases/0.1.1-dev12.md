# Juna 0.1.1-dev12

Settings → Updates now offers Stable/Preview channels, Check, Download and Install & Restart.
Downloads come from published GitHub Releases, with size limits, HTTPS, checksums and native
version/source verification. The install confirmation defaults to Cancel. Close other Juna
windows before installing; this window's tabs will be closed and reaped.

A hidden Rust helper retries replacing the locked executable after Juna exits, installs matching
notices, retains the previous files and restarts the configured interactive shell. A first-frame
startup acknowledgement gates success; handled replacement/restart failures restore the old
version. Settings/themes remain local. No telemetry or automatic network polling was added.

This is a development updater. Integrity checks are not publisher signatures. An interrupted
helper or power loss requires manual recovery from the retained .juna-rollback files or a complete
verified release ZIP; automatic crash recovery is not claimed. Old backup/staging retention is
currently manual. Physical input, other machines and stable acceptance remain separate testing.

Includes dev11's home-directory startup. Builds before dev12 need one manual download to gain
the updater; subsequent releases can be installed through Settings.

Redraw preparation now reuses contrast results and storage and avoids per-cell text/glyph
allocations. A controlled desktop CPU probe improved ordinary text from 2.12 ms to 0.95 ms
and light coloured boxes from 14.71 ms to 0.99 ms. These are preparation timings, not input
latency or FPS. PERFORMANCE.md records the comparison methodology and remaining memory/laptop
work; the laptop performance problem is not claimed resolved.
