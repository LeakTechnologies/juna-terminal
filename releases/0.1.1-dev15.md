# Juna 0.1.1-dev15

Repairs Junafetch protected-field reveal through ConPTY. Hold Shift, then move over a shaded
field to reveal its value. Releasing Shift, leaving the field or losing focus hides it.
Ordinary masks now match display width, including wide/combining Unicode. Explicitly typed
password masks use exactly eight asterisks; Junafetch does not collect passwords.

Values stay outside terminal output, scrollback and normal clipboard copies. This protects
Junafetch structured fields; arbitrary command output is not automatically censored.
The earlier reveal evidence missed a ConPTY marker-association defect; new integration tests
exercise actual bundled output through the app's hit-testing and reveal handling.

Windows 10 1809 or later is required. Other-machine and stable acceptance remain separate
from build and controlled runtime validation.

Validation: required check/lint and 237 standard tests, nine frontend tests, six GPU tests
and eight real-window tests passed locally. New synthetic GPU captures were visually reviewed.
