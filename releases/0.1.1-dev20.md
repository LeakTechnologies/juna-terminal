# Juna 0.1.1-dev20

Add a separate developer benchmark utility, built from source with
`cargo build --release --bin juna-bench`. It is not bundled in the normal terminal ZIP
and adds no benchmark menu or capture activity to ordinary sessions.

The first adapter runs freshly owned, isolated Juna windows with synthetic ASCII,
Unicode, colour and continuous-output workloads. Local JSON and standalone HTML reports
record parent CPU/private memory/working set, committed region categories, warm fixture
startup and targeted input response confirmed by distinct captured colour markers.
Capture has a supervised subprocess and no desktop/monitor fallback.

Response values include capture/file-coordination/polling overhead, not physical display
latency. Memory excludes child/helper/GPU allocations. Cross-terminal comparisons, true
Ctrl+C response, scroll interaction and multi-session tests remain future work.
No terminal performance fix or resolved laptop experience is claimed in this cycle.

See BENCHMARKS.md for usage, scope and limitations. Local validation and sanitised counters
are recorded in DONE.md and docs/performance/dev20. Hosted release checks and downloadable
assets must be verified after tagging; local tests alone do not establish publication.
