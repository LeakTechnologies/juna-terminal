# Juna 0.1.1-dev2 — preserve read-only JSON files

Refuse replacement of existing read-only settings/export files on every platform before staging
a write. Atomic rename on Unix can otherwise replace a read-only file; this caused the import
rollback regression in Linux CI to miss the intended failure. Original preferences and staged-theme
rollback are now covered on Windows and Linux. Windows terminal UI behavior is unchanged.

Development preview, not stable acceptance. Required local checks and the fresh hosted Linux/
Windows workflows verify this cycle; published assets retain version/source/icon and hash checks.
Dev1 remains an immutable published Windows preview. Junafetch/fetch delivery is the next feature
cycle; this small CI correction has its own sequential version under the release cadence.
